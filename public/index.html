THE IDEA

A review trail, not a victory badge.

Roadtest starts with a short list of claims, then records the checks that actually support each one. A pass applies only to that scope.

⌁

    WALLET TRANSACTION EVIDENCE

    Check a real transaction.

    Sign a transaction in the project you are testing, then paste its hash here. Roadtest checks the GenLayer network independently; it never asks for your private key.

    A passing receipt confirms the transaction finalized, executed successfully, and reached the stated contract. It does not prove every app action or claim.

    IMPORTANT CONTEXT

    What this does not prove

      Public responses are operated by the target. Browser screenshots come from the CI runner. These are review evidence, not cryptographic proof of every click or a security guarantee.

      BUILT FOR AGENTS TOO

      Let your agent read the evidence.

      Agents can submit a public-site plan to POST /api/run, read its published report JSON, and verify a GenLayer transaction at POST /api/receipt. These reads need no wallet; any new on-chain write must be signed by its requester.
